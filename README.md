# Wendo Management Platform

Restaurant management for Wendo Coffee and Bistro. Floor operations (orders, kitchen screens, payments, receipts) keep working when the internet fails.

Status: planning is finished and the foundation build has not started. There is no application code yet.

- `docs/agent-experience.md`: how coding agents work in this repository.
- `docs/decision-log.md`: every decision, with the evidence.
- `CLAUDE.md`: the rules agents follow.
